## 1. Markdown 渲染缺失

### 问题

`TraveloguePage.vue:106-108` — `formatContent` 只做了 `\n → <br>`，AI 生成的所有 Markdown 语法（标题、列表、加粗、图片）均显示为纯文本。

当前代码：

```typescript
function formatContent(text: string): string {
  return text.replace(/\n/g, '<br>')
}
```

### 涉及文件

- `frontend/src/views/TraveloguePage.vue`
- `frontend/package.json`（新增依赖）

### 修改方案

**① 安装依赖**

```bash
cd frontend
npm install marked dompurify
npm install --save-dev @types/dompurify
```

**② 引入并替换渲染函数** — `TraveloguePage.vue`

```diff
+ import { marked } from 'marked'
+ import DOMPurify from 'dompurify'

  function formatContent(text: string): string {
-   return text.replace(/\n/g, '<br>')
+   const raw = marked.parse(text, { breaks: true }) as string
+   return DOMPurify.sanitize(raw)
  }
```

**③ 更新样式** — 替换 `.markdown-body` 样式以正确显示 Markdown：

```css
/* 替换现有的 .markdown-body */

  line-height: 1.8;

.markdown-body h3 { font-size: 17px; margin: 16px 0 8px; }
.markdown-body p { margin: 0 0 12px; }
.markdown-body ul, .markdown-body ol { padding-left: 24px; margin: 0 0 12px; }
.markdown-body li { margin-bottom: 4px; }
.markdown-body blockquote {
  border-left: 4px solid #1890ff;
  margin: 12px 0;
  padding: 8px 16px;
  background: #f8f9fa;
  color: #666;
}
.markdown-body img {
  max-width: 100%;
  border-radius: 8px;
  margin: 12px 0;
}
.markdown-body strong { font-weight: 600; }

  background: #f5f5f5;
```

### 效果预期

## 3. 详情页缺少「分享」按钮

### 涉及文件

- `frontend/src/views/TraveloguePage.vue`

```diff

+     <button v-if="!isShareView && store.current?.status === 'published'"
+             class="btn btn-outline" @click="handleShare">🔗 分享</button>
+   </div>
  </div>
```

**② 分享处理函数**

```typescript
import { useTravelogueStore } from '@/store/travelogueStore'

const travelogueStore = useTravelogueStore()
const showShareModal = ref(false)
const shareUrl = ref('')
const sharePassword = ref('')

async function handleShare() {
  if (!travelogueId.value) return
  try {
    const result = await travelogueStore.share('travelogue', travelogueId.value)
    if (result) {
      shareUrl.value = result.share_url
      showShareModal.value = true
    }
  } catch {
    uiStore.showError('生成分享链接失败')
  }
}

function copyShareLink() {
  navigator.clipboard.writeText(shareUrl.value)
  uiStore.showSuccess('链接已复制')
}
```

## 4. 缺少删除功能（UI 联动）

### 问题

后端需先添加 DELETE 端点（见后端修复方案），然后前端需添加删除确认 UI。

### 涉及文件

- `frontend/src/views/TraveloguePage.vue`
- `frontend/src/api/travelogue.ts`
- `frontend/src/store/travelogueStore.ts`

### 修改方案

**① API 层** — `frontend/src/api/travelogue.ts`

```typescript
export function deleteTravelogue(id: string) {
  return http.delete<ApiResponse<null>>(`/travelogues/${id}`)
}
```

**② Store** — `frontend/src/store/travelogueStore.ts`

```typescript
async function remove(id: string) {
  await deleteTravelogue(id)
  travelogues.value = travelogues.value.filter(t => t.id !== id)
  if (current.value?.id === id) {
    current.value = null
  }
}
```

**③ 详情页工具栏添加删除按钮**

```diff
  <div class="toolbar-right">
+   <button class="btn btn-danger" @click="handleDelete">🗑️ 删除</button>
  </div>
```

```typescript
async function handleDelete() {
  if (!travelogueId.value) return
  const confirmed = confirm('确定删除这篇游记吗？此操作不可撤销。')
  if (!confirmed) return
  try {
    await travelogueStore.remove(travelogueId.value)
    uiStore.showSuccess('游记已删除')
    router.push('/travelogues')
  } catch {
    uiStore.showError('删除失败')
  }
}
```

**④ 列表页添加右键/操作菜单删除**

在 `TravelogueListPage.vue` 的 `a-list-item` 中添加操作按钮：

```diff

    <a-list-item-meta>...</a-list-item-meta>
+   <template #actions>
+     <a-popconfirm title="确定删除该游记？" @confirm.stop="handleDelete(item.id)">
+       <a-button type="text" danger @click.stop>删除</a-button>
+     </a-popconfirm>
```

## 6. XSS 安全隐患

`v-html` 直接渲染用户内容，无过滤。

```html
<div class="markdown-body" v-html="formatContent(store.current.content)"></div>
```

### 涉及文件

- `frontend/src/views/TraveloguePage.vue`

### 修改方案

由 **第1节** 的 DOMPurify 自动解决。若暂时不引入 marked，也应先做 sanitize：

```typescript
import DOMPurify from 'dompurify'

function formatContent(text: string): string {
  return DOMPurify.sanitize(text.replace(/\n/g, '<br>'))
}
```

## 7. 列表页缺少 loading / empty / error 状态

### 问题

`TravelogueListPage.vue` 使用 `onMounted` 直接调用 `store.fetchList()`，无 loading、无错误处理、无重试。

### 涉及文件

- `frontend/src/views/TravelogueListPage.vue`

### 修改方案

**① 添加状态变量**

```typescript
const isLoading = ref(true)
const error = ref<string | null>(null)

onMounted(async () => {
  isLoading.value = true
  error.value = null
  try {
    await store.fetchList()
  } catch (e) {
    error.value = '加载失败，请重试'
  } finally {
    isLoading.value = false
  }
})

function retry() {
  onMounted()
}
```

**② 三种状态渲染**

```vue
<!-- loading -->
<div v-if="isLoading" class="state-center">
  <a-spin size="large" />
  <p>加载中...</p>
</div>

<!-- error -->
<div v-else-if="error" class="state-center">
  <a-result status="error" :title="error">
    <template #extra>
      <a-button type="primary" @click="retry">重新加载</a-button>
    </template>
  </a-result>
</div>

<!-- empty (使用 Ant Design 的 a-empty) -->
<a-empty v-else-if="!publishedList.length && !draftList.length" description="还没有游记">
  <template #extra>
    <a-button type="primary" @click="showGenerateModal = true">生成第一篇游记</a-button>
  </template>
</a-empty>
```

## 8. 组件库风格不一致

### 问题

| 页面 | 组件库 |
|------|--------|
| `TravelogueListPage` | Ant Design Vue |

风格、间距、颜色体系均不一致。

### 涉及文件

- `frontend/src/views/TraveloguePage.vue`

### 修改方案（选做，建议 V2.1）

将 `TraveloguePage.vue` 的自定义元素替换为 Ant Design 组件：

| 自定义元素 | Ant Design 组件 |
|-----------|----------------|
| `.btn` | `<a-button>` |
| `.edit-title-input` | `<a-input>` |
| `.edit-content-textarea` | `<a-textarea>` |
| `.edit-toolbar` | `<a-page-header>` |
| `.cover-section` | 自定义 + Ant Image |
| `.meta span` | `<a-tag>` / `<a-statistic>` |
| `.material-sidebar` | `<a-drawer>` |

**方案 B：统一到自定义 CSS**

将 `TravelogueListPage.vue` 的 Ant Design 组件替换为手写实现。

**建议：** 方案 A 更现实，工作量可控，且项目中到处使用了 Ant Design。

## 9. 修复优先级与建议顺序

| 优先级 | 修复项 | 工作量 | 影响面 |
|--------|--------|--------|--------|
| **P0** | Markdown 渲染 | 小（~1h） | 核心功能：内容不可读 ❗ |
| **P0** | XSS 过滤 | 小（~0.5h） | 安全漏洞 |
| **P0** | 列表页 loading/error | 小（~1h） | 用户体验基础 |
| **P1** | 「生成游记」入口 | 中（~2h） | 用户无法主动创建 |
| **P1** | 删除功能（UI） | 小（~1h） | 数据管理 |
| **P2** | 分享按钮 | 小（~1h） | 分享功能不可用 |
| **P2** | 素材生成触发 | 小（~1h） | 功能半成品 |
| **P3** | 组件库统一 | 大（~4h） | 视觉一致性 |

> **建议执行顺序：**
> - 第1轮（P0）：Markdown 渲染 + XSS 过滤 + 列表页 loading 状态
> - 第2轮（P1）：生成游记入口 + 删除功能
> - 第3轮（P2）：分享按钮 + 素材生成触发
> - 第4轮（P3）：统一组件风格
