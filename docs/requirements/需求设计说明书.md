## 1. 系统概述

本系统是一个基于多智能体架构的旅行规划平台。通过 **7 个业务智能体**协作，为用户提供从自然语言对话到结构化旅行方案的一站式规划服务。

### 1.1 核心特点

| 特点 | 说明 |
|---|---|
| 自然语言交互 | 用户用对话描述需求，系统自动提取参数并生成方案 |
| 多智能体协作 | 7 个专业智能体各司其职，并行规划提升效率 |
| 流式输出 | 对话、规划进度、最终方案全程 SSE 流式返回 |
| 三级数据兜底 | 向量库 RAG → 结构化数据库 → 外部 API 自动降级 |
| 确定性预算算法 | 预算核算使用纯算法，不依赖 LLM（符合 D-004 决策） |

### 1.2 技术栈

- **后端**：FastAPI + Pydantic + LangGraph（StateGraph 编排）
- **数据层**：Chroma 向量库 + PostgreSQL + BGE Embedding
- **外部服务**：高德地图 API、和风天气 API、12306、美团酒旅 CLI
- **安全**：JWT（HS256）+ bcrypt

## 3. 功能需求

### F1 对话交互

| 编号 | 需求 | 状态 |
|---|---|---|
| F1.1 | 用户通过自然语言描述旅行需求（目的地、出发地、天数、预算等） | ✅ |
| F1.2 | 系统自动提取结构化参数，识别缺失信息 | ✅ |
| F1.3 | 4 项必填信息（destination/origin/days/budget）完整后标记 ready，触发规划 | ✅ |
| F1.4 | 多轮对话，支持上下文延续（加载最近 50 条历史） | ✅ |
| F1.5 | 在景点、美食、住宿、预算询问前，给出选项按钮帮助用户快速确认偏好/口味/需求 | 🔸 未实现 |
| F1.6 | 对用户的模糊语义给出选项进行确认（如"想去好玩的地方"→列出自然/人文/都市选项） | 🔸 未实现 |

> 实现组件：UserInteractionAgent

### F2 景点推荐

| 编号 | 需求 | 状态 |
|---|---|---|
| F2.1 | 基于目的地和偏好，从 Chroma 向量库语义检索候选景点 | ✅ |
| F2.2 | 候选不足时自动调用 seed_poi 脚本拉取 POI 入库后重搜 | ✅ |
| F2.3 | LLM 对景点排序并按天分配，生成推荐理由 | ✅ |
| F2.4 | 从 PostgreSQL 补全坐标、评分等结构化信息 | ✅ |

> 实现组件：AttractionAgent

### F3 美食推荐

| 编号 | 需求 | 状态 |
|---|---|---|
| F3.1 | 基于目的地从向量库检索候选餐厅 | ✅ |
| F3.2 | LLM 分配每日午餐和晚餐，生成推荐理由 | ✅ |
| F3.3 | 候选不足时自动拉取 POI | ✅ |

> 实现组件：FoodAgent

### F4 住宿推荐

| 编号 | 需求 | 状态 |
|---|---|---|
| F4.1 | 优先调用美团酒旅 API 获取真实价格和评分 | ✅ |
| F4.2 | 美团不可用时降级到向量库检索 | ✅ |
| F4.3 | 候选不足时自动拉取 POI | ✅ |
| F4.4 | LLM 筛选酒店并生成推荐理由 | 🟡 缺失 |

> 实现组件：HotelAgent

### F5 方案决策

| 编号 | 需求 | 状态 |
|---|---|---|
| F5.1 | 整合景点、美食、酒店三路规划为每日行程 | ✅ |
| F5.2 | 景点数量超过阈值时提示用户确认 | ✅ |
| F5.3 | 逐日人机交互选择（"Day1 上午 A/B 选哪个"粒度） | 🔸 未实现 |
| F5.4 | 细粒度行程微调：支持自然语言局部修改（如"第二天下午太累了，换个近点的咖啡馆"），系统精准定位并局部重算，无需推翻整个行程 | 🔸 未实现 |

### F6 交通规划

|---|---|---|

| F6.3 | 高德 API 失败时降级为 Haversine 直线距离估算 | ✅ |

## 4. 数据需求

### 4.1 三级数据兜底策略

景点、美食、酒店数据采用统一的三级兜底：

| 层级 | 数据源 | 用途 | 状态 |
|---|---|---|---|
| 第一级 | Chroma 向量库（BGE Embedding） | 语义检索，快速匹配 | ✅ |
| 第二级 | PostgreSQL 结构化数据 | 补全坐标、评分、价格 | ✅ |
| 第三级 | 外部 API + seed_poi 脚本 | 候选不足时自动拉取入库后重搜 | ✅ |

### 4.2 外部服务依赖

| 服务 | 用途 | 调用方 | 状态 |
|---|---|---|---|
| 高德 Direction API | 市内交通路径 | TrafficAgent | ✅ |
| 美团酒旅 CLI | 酒店价格和评分 | HotelAgent | ✅ |
| 12306 | 火车票查询 | 编排层 | ✅ |
| 和风天气 API | 天气预报 | WeatherAgent | ✅（未编排） |
