## 一、设计理念与品牌调性

### 1.1 品牌核心词

| 维度 | 关键词 | 设计表现 |
|------|--------|---------|
| **情感** | 温度 · 治愈 · 期待 | 暖色调、柔和光影、手绘质感 |
| **品质** | 精致 · 可靠 · 专业 | 严谨间距、清晰层级、克制动效 |
| **灵感** | 探索 · 诗意 · 在地 | 地理元素、自然肌理、人文氛围 |
| **智能** | 高效 · 轻盈 · 无感 | 毛玻璃面板、渐隐过渡、流畅反馈 |

### 1.2 设计隐喻

以 **「旅行手账」** 为核心设计隐喻：

> 每一段旅程都是一本独一无二的手账本
> - **封面** → 方案概览（目的地印象卡片）
> - **内页** → 每日行程（时间线叙事）
> - **贴纸/标签** → 活动类型标识（彩色徽章）
> - **手写批注** → AI 旅行贴士（手写体引用）
> - **票据/地图** → 交通与地图组件
> - **照片** → 目的地沉浸式图片

### 1.3 设计气质坐标

```
                   精致/高级
                      │
                      │
    冷静 ─────────────┼──────────── 温暖
                      │
                      │
                   朴素/自然
```

目标定位：**温暖不甜腻，精致不冰冷** —— 偏右上方象限。

## 二、色彩体系

### 2.1 品牌主色调

基于「旅途温度」与「大地美学」，选取**温暖杏色系**作为品牌核心色，取代传统旅行 App 的冷蓝色系。

| 色阶 | Token | 色值 | 用途 |
|------|-------|------|------|
| 50  | `--color-brand-50`  | `#FFF7F0` | 最浅背景、卡片底色 |
| 100 | `--color-brand-100` | `#FFEDDB` | 悬停背景、轻量填充 |
| 200 | `--color-brand-200` | `#FFD9B3` | 标签底色、进度条轨道 |
| 300 | `--color-brand-300` | `#FFBF82` | 次要元素、装饰线 |
| 400 | `--color-brand-400` | `#F5A35C` | 辅助强调色 |
| **500** | **`--color-brand-500`** | **`#E8A87C`** | **品牌主色（标准态）** |
| 600 | `--color-brand-600` | `#D49366` | 主色 Hover 态 |
| 700 | `--color-brand-700` | `#B87A50` | 主色 Active 态 |
| 800 | `--color-brand-800` | `#96633E` | 深色背景上的强调色 |
| 900 | `--color-brand-900` | `#7A4E2F` | 最深品牌色 |

> **设计理由**：杏色（#E8A87C）介于橙与粉之间，兼具活力与温柔，使人联想到日出、沙滩、收获等旅行意象，比蓝色更具情感温度和差异化识别度。

### 2.2 辅助色 — 大地色谱

从自然风物中提取辅助色系，构建完整的大地色盘：

| 色系 | Token | 色值 | 意象 | 用途 |
|------|-------|------|------|------|

| 石灰色 | `--color-stone` | `#A8B5A0` | 石灰岩、橄榄 | 边框、中性元素 |
| 沙黄色 | `--color-sand` | `#D4C5A9` | 沙漠、沙滩 | 背景色、卡片底色 |

| 天空蓝 | `--color-sky` | `#7EB8DA` | 晴空 | 链接、信息标识 |
| 湖绿色 | `--color-lake` | `#5B9B8C` | 湖水 | 环保、可持续标签 |

### 2.3 功能色

| 语义 | Token | 色值 | 用途 |
|------|-------|------|------|
| 成功 | `--color-success` | `#5BB98A` | 操作成功、完成状态 |
| 警告 | `--color-warning` | `#E8A837` | 注意提示、待办事项 |
| 错误 | `--color-error` | `#D9605C` | 错误提示、删除操作 |
| 信息 | `--color-info` | `#7EB8DA` | 信息提示、帮助说明 |

功能色使用规则：
- 饱和度控制在 50%-65% 之间，比品牌色低一个饱和梯度，避免视觉冲突
- 错误色选用暖红（偏橙）而非冷红（偏蓝），与整体暖调统一
- 成功色选用草木绿，呼应自然意象

## 六、圆角系统

### 6.1 圆角变量

| Token | 值 | 用途 |
|-------|-----|------|
| `--radius-none` | 0 | 无圆角（极少数情况） |
| `--radius-sm` | 6px | 输入框、按钮、小元素 |
| `--radius-md` | 12px | 卡片标准圆角 |
| `--radius-lg` | 16px | 大卡片、面板 |
| `--radius-xl` | 24px | 弹窗、大面板 |
| `--radius-full` | 50% | 圆形（头像、徽标） |
| `--radius-pill` | 999px | 药丸形（标签、开关） |

### 6.2 圆角设计原则

- 卡片类采用 **12px 圆角**，温润不尖锐
- 按钮和输入框采用 **6px 圆角**，平衡亲和与效率
- 弹窗和抽屉采用 **16-24px 大圆角**，营造优雅感
- 标签和徽章采用 **药丸形** 圆角，活泼友好
- 避免同时使用多个差异过大的圆角，保持视觉一致性

## 七、毛玻璃质感规范

### 7.1 基础参数

```css
--glass-bg: rgba(255, 247, 240, 0.72);
--glass-border: rgba(255, 255, 255, 0.3);
--glass-shadow: 0 4px 16px rgba(139, 115, 85, 0.10);
--glass-blur: 16px;
```

### 7.2 应用场景

| 场景 | 毛玻璃参数 | 说明 |
|------|-----------|------|
| 固定导航栏 | `rgba(252, 249, 245, 0.80)` + blur(12px) | 页面顶部，内容透出 |
| 底部操作栏 | `rgba(252, 249, 245, 0.85)` + blur(16px) | 移动端底部固定栏 |
| 抽屉面板 | `rgba(255, 247, 240, 0.92)` + blur(20px) | ActivityDrawer 背景 |
| 弹窗遮罩 | `rgba(44, 44, 44, 0.4)` | 非玻璃，标准遮罩 |
| 数据卡片悬浮 | `rgba(255, 255, 255, 0.6)` + blur(8px) | 地图上悬浮信息卡片 |
| 移动端侧栏 | `rgba(252, 249, 245, 0.88)` + blur(14px) | Drawer 模式侧栏 |

### 7.3 毛玻璃使用原则

1. **层次感优先**：毛玻璃用于需要表达层级关系的场景（浮动层 > 内容层 > 背景层）
2. **不滥用**：一张页面上毛玻璃元素不超过 3 个
3. **深色背景/图片上效果好**：在纯色浅背景上毛玻璃效果不明显
4. **性能注意**：`backdrop-filter: blur()` 在移动端有性能开销，控制使用面积

## 八、图标系统

### 8.1 图标风格

| 维度 | 规范 |
|------|------|
| 风格 | **线性 + 圆角端点**（Line Style, Round Cap） |
| 线条宽度 | 1.5px / 2px（大尺寸图标用 2px） |
| 端点 | 圆头端点（`stroke-linecap: round`） |
| 连接 | 圆角连接（`stroke-linejoin: round`） |
| 尺寸 | 16px / 20px / 24px / 32px 四档 |
| 图标库 | 优先使用 **Lucide Icons**（风格统一，MIT 许可） |
| 备用库 | Heroicons（Outline）+ 自定义旅行图标 |

### 8.2 活动类型图标映射

每种活动类型对应一个独特的 Lucide 图标，保证识别一致性：

| 活动类型 | 图标名（Lucide） | 自定义替代 |
|---------|-----------------|-----------|
| 交通 · 飞行 | `plane` | ✈️ |
| 交通 · 火车 | `train` | 🚄 |
| 交通 · 驾车 | `car` | 🚗 |
| 交通 · 公交 | `bus` | 🚌 |
| 景点 | `landmark` | 🏛️ |
| 自然景点 | `mountain` | 🏔️ |
| 美食 | `utensils-crossed` | 🍜 |
| 购物 | `shopping-bag` | 🛍️ |
| 休息 | `coffee` | 😴 |
| 娱乐 | `ticket` | 🎭 |
| 住宿 · 酒店 | `bed-double` | 🏨 |

### 8.3 图标使用规则

- 导航类图标使用 24px 尺寸
- 行内操作图标使用 16px 尺寸
- 卡片标题图标使用 20px 尺寸
- 品牌标识和空状态使用 32px+ 尺寸
- 所有图标必须对齐到 4px 网格
- 图标用 `currentColor` 填充，随文本颜色变化

## 九、图片与插画风格

### 9.1 目的地摄影图片处理

| 处理项 | 规范 |
|-------|------|
| 图片色调 | 统一暖调滤镜（色温 +5，饱和度 -10%） |

## 十四、动效规范

### 14.1 缓动函数

```css
--ease-out-expo: cubic-bezier(0.16, 1, 0.3, 1);    /* 出场 —— 干脆优雅 */
--ease-in-out: cubic-bezier(0.4, 0, 0.2, 1);        /* 标准 —— 通用过渡 */
--ease-spring: cubic-bezier(0.34, 1.56, 0.64, 1);   /* 弹性 —— 轻快活泼 */
--ease-smooth: cubic-bezier(0.65, 0, 0.35, 1);      /* 平滑 —— 线性感 */
```

### 14.2 时长体系

| Token | 时长 | 用途 |
|-------|------|------|
| `--dur-instant` | 50ms | 微交互反馈（按钮按下） |
| `--dur-fast` | 150ms | 悬停态变化、图标旋转 |
| `--dur-normal` | 250ms | 标准过渡（展开/折叠/切换） |
| `--dur-slow` | 400ms | 面板出入、淡入淡出 |
| `--dur-slide` | 300ms | 抽屉滑入/滑出 |
| `--dur-enter` | 500ms | 页面入场、骨架屏→内容 |
| `--dur-stagger` | 80ms | 列表逐项延迟 |

### 14.3 场景动效定义

| 场景 | 属性 | 时长 | 缓动 | 说明 |
|------|------|------|------|------|
| 页面切换 | opacity + translateY(12px→0) | 400ms | ease-out-expo | 新页面淡入上滑 |
| 卡片入场 | opacity + scale(0.96→1) | 300ms | ease-out-expo | 卡片逐张显现 |
| 列表项入场 | opacity + translateY(8px→0) | 250ms | ease-out-expo | 逐项延迟 80ms |
| 抽屉滑入 | translateX(100%→0) | 300ms | ease-out-expo | 右侧抽屉面板 |
| 展开/折叠 | height auto | 250ms | ease-in-out | 活动项展开详情 |
| 按钮 Hover | transform: scale(1.02) | 150ms | ease-spring | 轻微放大 |
| 按钮点击 | transform: scale(0.97) | 50ms | ease-in-out | 按下反馈 |
| Skeleton → 内容 | opacity | 350ms | ease-smooth | 交叉淡入淡出 |
| 打字机效果 | 字符逐个出现 | 30-50ms/字 | — | requestAnimationFrame 驱动 |
| 地图标注弹跳 | translateY | 400ms | ease-spring | 新标注点出现 |
| Toast 出入 | opacity + translateY | 250ms | ease-out-expo | 顶部滑入/滑出 |
| 折叠 Panel | height auto | 300ms | ease-in-out | DayCard 折叠切换 |

### 14.4 动效使用原则

1. **克制**：动效时长不超过 500ms，避免用户等待
2. **有意义**：每个动效服务于理解（状态变化）或愉悦（微交互），不纯为炫技
3. **可关闭**：尊重 `prefers-reduced-motion`，关闭后所有动效立即完成
4. **可打断**：正在执行的动效能被新操作中断，不阻塞交互
5. **一致性**：同类场景使用相同的时长和缓动函数

## 十六、暗色模式

### 16.1 暗色模式设计原则

1. **不是简单的颜色反转**——每对颜色都经过专门调整
2. **保持品牌识别**——品牌色在暗色模式下微调亮度，保持辨识度
3. **降低视觉疲劳**——背景用深灰而非纯黑（减少光晕）
4. **层次用亮度区分**——不同层级用不同明度的灰色表达，而非阴影

### 16.2 暗色模式色彩映射

| 亮色 Token | 暗色 Token (亮→暗) | 说明 |
|-----------|-------------------|------|
| `#FCF9F5` | `#1C1C1A` | 页面背景 |
| `#F7F2EB` | `#262622` | 次级背景 |
| `#F0EAE0` | `#302E2A` | 三级背景/Hover |
| `#FFFFFF` | `#2A2826` | 卡片背景 |
| `#2C2C2C` | `#E8E4DE` | 主要文字 |
| `#6B6B6B` | `#B0ABA4` | 次要文字 |
| `#E8E0D6` | `#403E3A` | 边框色 |
| `rgba(255,247,240,0.72)` | `rgba(38,38,34,0.80)` | 毛玻璃背景 |
| `rgba(255,255,255,0.3)` | `rgba(255,255,255,0.06)` | 毛玻璃边框 |

### 16.3 暗色模式品牌色微调

| 亮色 | 暗色 | 说明 |
|------|------|------|
| `#E8A87C` | `#E8A87C` | 品牌色保持不变（已足够柔和） |
| `#FFF7F0` | `#2A221E` | 品牌色 50 暗化 |
| `#FFEDDB` | `#3D3028` | 品牌色 100 暗化 |
| `#F5A35C` | `#D4945A` | 辅助强调色略暗化 |

### 16.4 暗色模式阴影调整

```css
--shadow-color-light: rgba(0, 0, 0, 0.20);
--shadow-color-base: rgba(0, 0, 0, 0.30);
--shadow-color-strong: rgba(0, 0, 0, 0.40);
```

暗色模式下阴影更强调深度感，使用纯黑阴影替代暖灰阴影。

### 16.5 暗色/亮色切换

- 默认跟随系统（`prefers-color-scheme`）
- 用户可手动切换，选择存储在 localStorage 中
- 切换动画：`document.startViewTransition()`（支持时）
- 品牌色系在两种模式下均保持视觉识别度
