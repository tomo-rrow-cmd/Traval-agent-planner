**四、 遇到的问题与困难**

*   **技术问题：**
    *   **CI/CD 环境适配困难**：从 Docker runner 切换到 shell runner 时遇到脚本解析错误、依赖冲突、Python 版本不一致、镜像仓库未配置等一系列问题，经过 6 轮修复才跑通
    *   **已尝试的解决方案：** 逐轮调整 `.gitlab-ci.yml`，统一 Python 3.12，跳过未配置的镜像推送，改为离线测试，最终适配 shell runner
    *   **并发安全设计挑战**：会话消息在高并发下可能出现 sequence 重复或脏数据，设计上选择了行级锁 + 数据库唯一约束双重保障方案
    *   **已尝试的解决方案：** 实现 `SELECT ... FOR UPDATE` 行级锁分配 sequence + `client_message_id` 幂等检测，通过 3 个真实 PostgreSQL 并发测试 (8/12/12 并发) 验证通过
    *   **需要帮助或待解决：** 无

*   **非技术问题：**
    *   本周单兵作战，前后端 + 文档 + DevOps 多条线并行，时间分配上偶尔有顾此失彼的情况
    *   **已采取的措施：** 日报制度帮助每天复盘，确保不遗漏关键任务；下周计划更明确地划分前后端时间
