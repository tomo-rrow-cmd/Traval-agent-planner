# AI 使用日志

记录在项目开发过程中使用 AI 工具（Claude Code、ChatGPT、GitHub Copilot 等）的情况，包括用途、关键决策和产出。

## 目录结构

```
reports/ai-logs/
├── README.md                          # 本文件
├── YYYY-MM.md                         # 月度使用日志（日常流水）
└── SprintN-AI使用反思报告.md           # 阶段回顾报告（里程碑总结）
```

- **月度日志**（`YYYY-MM.md`）：以天为单位，记录每次 AI 使用的用途、决策、产出
- **回顾报告**（`SprintN-AI使用反思报告.md`）：每个 Sprint/阶段结束时，对 AI 使用效果的全面复盘

## 月度日志格式

每条日志包含以下字段：

| 字段 | 说明 |
|------|------|
| **日期** | 使用日期 |
| **工具** | 使用的 AI 工具/模型 |
| **用途** | 本次使用 AI 的目的 |
| **关键决策** | AI 参与或辅助做出的重要技术决策 |
| **产出** | AI 协助完成的成果（文件、功能、修复等） |
| **备注** | 其他值得记录的信息 |
